# ROGIC 블록코딩 SW 요약 정리

---

## 📘 01) 블록코딩 SW Rogic 알기

1. **ROGIC 소개**: 로보로보의 DIYGO 로봇 시리즈를 위한 블록코딩 소프트웨어로, 스프라이트(캐릭터·오브젝트)와 배경을 활용해 프로그램을 만든다.

2. **다운로드 방법**: 로보로보 공식 사이트에서 Windows용 설치 파일을 다운로드하여 설치한다.

3. **화면 구성 4영역**: ① 메뉴바(저장·불러오기), ② 실행 창(결과 미리보기), ③ 스프라이트·배경·장치 관리 패널, ④ 블록/스크립트 영역으로 구성된다.

4. **스프라이트 조작**: 스프라이트를 추가·삭제하고 크기·위치·방향을 속성 패널에서 설정할 수 있으며, 여러 스프라이트를 동시에 관리할 수 있다.

5. **블록 조작법**: 블록 탭에서 원하는 블록을 스크립트 영역으로 드래그하여 연결하고, 불필요한 블록은 스크립트 밖으로 끌어내어 삭제한다.

6. **핵심 블록 조합**: 이벤트 블록(시작 조건)→제어 블록(반복·조건)→동작/형태 블록 순으로 연결하는 것이 기본 구성 패턴이다.

7. **음원 사용법**: 소리 탭에서 기본 제공 음원을 선택하거나 외부 파일을 불러온 뒤, "소리 재생" 블록으로 스크립트에서 호출한다.

## 📗 02) 블록코딩 SW Rogic 실습

1. **스프라이트 이동**: 방향키 이벤트 블록과 좌표 변경 블록을 조합하여 스프라이트를 상하좌우로 움직이게 하는 기본 이동 구현 방법을 익힌다.

2. **내 블록(함수)**: 반복 사용되는 블록 묶음을 "내 블록"으로 정의하면 코드 재사용이 가능해지고, 스크립트가 간결해진다.

3. **조건문**: "만약 ~ 이라면 / 아니라면" 블록으로 특정 조건(예: 벽 닿기, 키 입력)에 따라 다른 동작을 수행하도록 분기 처리한다.

4. **변수**: 변수를 생성하여 점수·횟수 등 변하는 값을 저장하고, 블록으로 값을 증감·초기화하여 게임 상태를 관리한다.

5. **난수**: "무작위 수" 블록으로 일정 범위 내 임의의 값을 생성해 스프라이트의 등장 위치나 속도를 무작위로 변화시킨다.

6. **신호(메시지)**: 한 스프라이트가 신호를 보내면 다른 스프라이트가 해당 신호를 받아 동작하는 방식으로, 스프라이트 간 협력·연동을 구현한다.

## 📙 03) Rogic 게임 프로젝트 실습

1. **스프라이트 제작 흐름**: 기본 제공 Apple 스프라이트를 복사하여 모양 탭에서 딸기·샤인머스켓으로 수정하고, 과일꼬치·설탕코팅 모양까지 단계별로 변형하여 탕후루 게임 캐릭터를 완성한다.

2. **게임 기본 구조**: 탕후루월드는 냄비 올리기 → 물 넣기 → 설탕 넣기 → 과일꼬치 담기 순서로 스프라이트를 클릭하는 제조 순서 게임으로, 각 단계를 신호로 연결하여 진행한다.

3. **변수 활용**: "탕후루 수" 변수를 생성하여 완성된 탕후루 개수를 기록하고, 과일꼬치 스프라이트가 설탕코팅 완료 신호를 받을 때마다 값을 1씩 증가시켜 점수를 관리한다.

4. **신호 체계**: 냄비올리기 → 물넣기 → 물완료 → 설탕완료 → 설탕코팅하기 순서로 신호를 순차 전달하여 각 스프라이트가 정해진 타이밍에 동작하도록 협력 구조를 구현한다.

5. **강조 시각 효과**: 스프라이트 클릭 시 색깔 효과 블록과 크기 변경 블록을 반복 적용하여 반짝이거나 커졌다 작아지는 시각적 피드백을 구현한다.

6. **스프라이트 복제**: "나 자신 복제하기" 블록으로 과일꼬치 스프라이트를 여러 개 생성하고, 각 복제본이 일정 위치에 나타나 설탕코팅 애니메이션을 수행하도록 제어한다.

## 📒 04) 로봇부품 이해하기

1. **프레임 구성**: 평면 프레임 7종(정사각형·직사각형·ㄱ자 등)과 L프레임 3종(90° 꺾임 연결용), 서포트 4종(7·15·30·40mm 높이)으로 DIYGO 로봇의 뼈대를 조립한다.

2. **조립 도구**: 너트 조임에는 자석 팁이 달린 육각 드라이버를, 볼트 조임에는 자석 팁이 달린 십자 드라이버를 사용하여 부품을 고정한다.

3. **좌표 시스템**: 프레임의 가로 방향은 알파벳(A·B·C…), 세로 방향은 숫자(1·2·3…)로 표기하여 부품 위치를 C6, F3처럼 알파벳+숫자 조합으로 지정한다.

4. **CPU보드 구성**: CPU보드는 모터 포트·센서 포트·통신 포트·전원 포트로 구성되며, 각 포트에 맞는 부품을 연결하여 로봇의 두뇌 역할을 한다.

5. **센서 종류**: 접촉센서(물리적 충돌 감지), 초음파센서(거리 측정), 자이로센서(기울기·회전 감지), 회전위치센서(모터 각도 측정) 4가지 센서로 다양한 입력을 처리한다.

6. **통신 부품**: 컴보드와 통신 케이블로 유선 연결하거나 블루투스 모듈을 CPU보드와 PC에 각각 장착하여 무선 통신을 구성하며, 배터리케이스는 전원을 공급한다.

7. **3핀 케이블 배선 규칙**: 3핀 케이블 연결 시 보드의 흰색 삼각형(◁) 표시 위치에 검정 선을 맞춰 꽂으며, 방향을 반대로 연결하면 부품이 손상될 수 있다.

## 📕 05) 로봇 연결하기

1. **로보키트:RS 확장 기능 추가**: Rogic 소프트웨어에서 로보키트:RS 확장을 추가하면 로봇 제어용 전용 블록 카테고리가 생성되어 모터·센서 제어 블록을 사용할 수 있다.

2. **유선 연결 3단계**: ① 컴보드를 PC의 USB 포트에 연결 → ② 통신 케이블로 컴보드와 CPU보드를 연결 → ③ Rogic에서 연결 버튼을 눌러 포트를 선택하면 유선 연결이 완료된다.

3. **펌웨어 업데이트**: 최초 연결 시 1회에 한해 CPU보드 펌웨어 업데이트를 진행해야 하며, 업데이트 완료 후 정상적으로 로봇을 제어할 수 있다.

4. **무선(블루투스) 연결**: 블루투스 모듈을 CPU보드와 PC 측(컴보드 대신)에 각각 장착한 뒤 Rogic에서 재연결하면 케이블 없이 무선으로 로봇을 제어할 수 있다.

5. **연결 확인 방법**: Rogic 화면 상단의 연결 상태 표시가 초록색으로 바뀌면 정상 연결된 것이며, 빨간색이면 포트 선택이나 케이블·블루투스 모듈 상태를 재확인해야 한다.

## 📔 06) 게임메이커 실습1

1. **로봇 조립 순서**: 하프프레임에 7mm 서포트와 너트로 기초를 잡고, 옵션프레임·CPU보드→바퀴→L 2X2프레임→배터리케이스→메인프레임→접촉센서 순으로 총 16단계에 걸쳐 참참참 대전 게임 로봇을 조립한다.

2. **케이블 배선 규칙**: 왼쪽 접촉센서1은 CPU보드 D13포트에, 오른쪽 접촉센서2는 D12포트에, 배터리케이스는 B1포트에 3핀 케이블(검·빨·노 색상 주의)로 각각 연결한다.

3. **게임 개요**: 로봇과 '참참참'을 하는 5라운드 대전 게임으로, 접촉센서1(왼쪽)·접촉센서2(오른쪽)을 눌러 손 방향을 선택하면 로봇도 동시에 고개를 돌려 승패를 결정한다.

4. **스프라이트 구성**: 로봇(정면·오른쪽·왼쪽·승리·패배 5모양), 손(손_정면·손_왼쪽·손_오른쪽 3모양), 1~5Round결과(준비·승리·패배 3모양), 꽃가루(꽃가루_1·꽃가루_2) 4종으로 게임을 구성한다.

5. **신호 체계**: 손 스프라이트가 '시작' 신호를 보내면 로봇이 난수(2~3)로 모양을 결정하고, 결과에 따라 '로봇승리' 또는 '로봇패배' 신호를 각 라운드 결과 스프라이트로 전달하며, 5라운드 완료 후 '끝' 신호를 보낸다.

6. **변수와 점수 관리**: '라운드'(1로 초기화)와 '점수'(0으로 초기화) 두 변수를 사용하며, 플레이어가 이길 때마다 점수를 1씩 증가시키고 라운드를 1씩 올려 5라운드까지 진행한다.

7. **최종 결과 처리**: '끝' 신호를 받았을 때 점수가 2보다 높으면 팡파레 효과음과 함께 꽃가루 애니메이션(꽃가루_1·꽃가루_2 모양 교체)이 재생되고, 2점 이하이면 2초 후 게임이 종료된다.

## 🔖 09) 게임메이커 실습4

1. **조준경 로봇 조립 순서**: 5X13프레임·120도프레임·접촉센서·ㅁ프레임→15mm 서포트→30mm 서포트·배터리케이스→7mm 서포트·5X13프레임→L 2X1프레임→회전위치센서→바퀴→자이로센서→CPU보드→접촉센서2 순으로 총 26단계에 걸쳐 조준경 로봇을 조립한다.

2. **케이블 배선 규칙**: 접촉센서1은 CPU보드 D13포트에, 접촉센서2는 D2포트에, 회전위치센서는 A0포트에, 자이로센서 A4·A5포트는 CPU보드 A4·A5포트에, 배터리케이스는 B1포트에 3핀 케이블(검·빨·노 색상 주의)로 연결하고 블루투스 무선 연결한다.

3. **회전위치센서 개념**: 다이얼의 회전 데이터를 측정하는 센서로, 한 바퀴 회전 시 0~1,000의 아날로그 값, 360도마다 [회전] 값 1씩 누적, 1도마다 [위치] 값 1씩 누적, -180~180 범위의 [각도] 값 4가지 방식으로 데이터를 제공하며 블록으로 0값 초기화할 수 있다.

4. **게임 개요**: '바퀴벌레 소탕 작전'은 20초 안에 바퀴벌레 5마리를 잡는 게임으로, 조준경을 위아래로 기울여 화면 y축을 이동하고 바퀴(회전위치센서)를 돌려 화면 x축을 이동한 뒤 접촉센서2(D2)를 눌러 살충제를 발사한다.

5. **스프라이트 구성 및 신호 체계**: 표적1~5(바퀴벌레-생존·퇴치 2모양)·조준경(1~9 모양)·시작신호(Ready·Go)·발사효과·결과(성공·실패) 5종 스프라이트로 구성되며, '확대→발사→명중→성공/실패' 신호 순서로 게임 흐름을 제어한다.

6. **조준경 이동 코딩**: 접촉센서1(D13) 누르면 자이로센서 방향을 '위로' 초기화하고 '확대' 신호를 보내 조준경 모양을 1→9번으로 전환한 뒤, 회전위치센서 위치값이 10 초과 시 x좌표 -5, -10 미만 시 x좌표 +5 이동하고 자이로센서 기울기y × 3을 y좌표로 설정하여 화면을 이동시킨다.

7. **바퀴벌레 명중 판정**: 접촉센서2(D2) 누르면 '발사' 신호와 효과음을 내보내고, 표적 스프라이트가 조준경 중앙 색에 닿았을 때 '명중' 신호를 보내 생존벌레를 -1 감소시키며 바퀴벌레-퇴치 모양으로 바꾼 뒤 살충제 분사 복제 효과를 재생한다.

## 📖 08) 게임메이커 실습3

1. **핸들 로봇 조립 순서**: ㅁ프레임·5x13프레임을 겹쳐 볼트·너트로 고정하고, 배터리케이스(A5·A9·E5·E9)→CPU보드+접촉센서(A4·A12)→7mm 서포트(D5·D9)→자이로센서 순으로 총 14단계에 걸쳐 조립한다.

2. **케이블 배선 규칙**: 접촉센서는 CPU보드 D13포트에, 자이로센서 A4포트는 CPU보드 A4포트에, 자이로센서 A5포트는 CPU보드 A5포트에, 배터리케이스는 B1포트에 3핀 케이블(검·빨·노 색상 주의)로 연결하고 블루투스 모듈로 무선 연결한다.

3. **게임 개요**: '추월의 제왕'은 자이로센서 핸들을 기울여 자동차를 조종하는 게임으로, 접촉센서를 눌러 시작하고 충돌하지 않게 주변 자동차를 추월할 때마다 추월횟수가 1씩 증가하며 충돌 시 게임이 종료된다.

## 🤖 14) 게임메이커 실습9

1. **이미지인식 AI 기능 개념**: ROGIC의 이미지인식 기술은 카메라에 담긴 화면 전체를 하나의 데이터로 학습시켜 유사 화면을 판단하는 기능으로, 최대 5개 클래스에 다양한 각도·거리의 사진을 촬영·학습시키고 분류결과·일치율·인식여부 블록으로 결과를 활용하며, .ipcc 파일로 학습 데이터를 저장·불러올 수 있다.

2. **이미지 학습 절차**: '영상 처리' + '비디오 감지' 확장을 추가 → 카메라 선택 후 '이미지 분류' 항목에서 클래스 생성 → 촬영 버튼으로 각 클래스 이미지 샘플 수집(꾹 눌러 연속 촬영 가능) → '학습하기' 버튼으로 학습 완료 → 체크박스 활성화로 무대 상단에서 실시간 분류 결과 확인한다.

3. **게임 개요**: '포즈 마스터'는 다가오는 모양벽(파·빨·노·초 4종)과 동일한 이미지를 카메라에 비춰 로보의 포즈를 맞추면 벽을 통과(+10점)하는 게임으로, 시작버튼 클릭 후 커튼이 열리며 벽이 등장하고, 로보가 물에 빠지면 실패, 100점(10번 통과)이면 성공한다.

4. **스프라이트 구성 및 신호 체계**: 로보·벽·실루엣·커튼·시작버튼·물보라·결과 7종 스프라이트로 구성되며, '시작→1~4번 포즈→실패→물보라' 신호 흐름으로 게임을 제어하고 성공은 점수 100점 도달로 판정한다.

5. **이미지 분류 기반 포즈 연동 코딩**: [실루엣] 스프라이트가 이미지 분류 결과에 따라 '1~4번 포즈' 신호를 전송하면 [로보] 스프라이트가 해당 포즈 모양(로보_1~4)으로 변경되고, 실루엣 스프라이트도 실루엣_파·빨·노·초 모양으로 동기화되어 현재 인식된 포즈를 좌측 상단에 미리 표시한다.

6. **벽 통과·실패 판정 코딩**: [벽] 스프라이트가 '벽이동' 내 블록으로 랜덤 모양으로 등장해 크기를 키우며 다가오고, 벽 모양과 로보 포즈가 일치하면 +10점, 불일치하면 '실패' 신호를 보내 로보가 뒤로 밀리며 물에 빠지는 애니메이션을 재생한다.

7. **결과 표시**: '실패' 신호 수신 시 이미지 분류 코드를 멈추고 [물보라] 스프라이트가 3모양 애니메이션을 재생 후 실패 결과 창을 띄워 게임을 종료하며, 점수가 100점(벽 10번 통과) 도달 시 성공 결과 창을 띄운다.
