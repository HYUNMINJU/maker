# ROGIC 블록코딩 SW 요약 정리

---

## 📘 01) 블록코딩 SW Rogic 알기

1. **ROGIC 소개**: 로보로보의 DIYGO 로봇 시리즈를 위한 블록코딩 소프트웨어로, 스프라이트(캐릭터·오브젝트)와 배경을 활용해 프로그램을 만든다.

2. **다운로드 방법**: 로보로보 공식 사이트에서 Windows용 설치 파일을 다운로드하여 설치한다.

3. **화면 구성 4영역**: ① 메뉴바(저장·불러오기), ② 실행 창(결과 미리보기), ③ 스프라이트·배경·장치 관리 패널, ④ 블록/스크립트 영역으로 구성된다.

4. **스프라이트 조작**: 스프라이트를 추가·삭제하고 크기·위치·방향을 속성 패널에서 설정할 수 있으며, 여러 스프라이트를 동시에 관리할 수 있다.

5. **블록 조작법**: 블록 탭에서 원하는 블록을 스크립트 영역으로 드래그하여 연결하고, 불필요한 블록은 스크립트 밖으로 끌어내어 삭제한다.

6. **핵심 블록 조합**: 이벤트 블록(시작 조건)→제어 블록(반복·조건)→동작/형태 블록 순으로 연결하는 것이 기본 구성 패턴이다.

7. **음원 사용법**: 소리 탭에서 기본 제공 음원을 선택하거나 외부 파일을 불러온 뒤, "소리 재생" 블록으로 스크립트에서 호출한다.

## 📗 02) 블록코딩 SW Rogic 실습

1. **스프라이트 이동**: 방향키 이벤트 블록과 좌표 변경 블록을 조합하여 스프라이트를 상하좌우로 움직이게 하는 기본 이동 구현 방법을 익힌다.

2. **내 블록(함수)**: 반복 사용되는 블록 묶음을 "내 블록"으로 정의하면 코드 재사용이 가능해지고, 스크립트가 간결해진다.

3. **조건문**: "만약 ~ 이라면 / 아니라면" 블록으로 특정 조건(예: 벽 닿기, 키 입력)에 따라 다른 동작을 수행하도록 분기 처리한다.

4. **변수**: 변수를 생성하여 점수·횟수 등 변하는 값을 저장하고, 블록으로 값을 증감·초기화하여 게임 상태를 관리한다.

5. **난수**: "무작위 수" 블록으로 일정 범위 내 임의의 값을 생성해 스프라이트의 등장 위치나 속도를 무작위로 변화시킨다.

6. **신호(메시지)**: 한 스프라이트가 신호를 보내면 다른 스프라이트가 해당 신호를 받아 동작하는 방식으로, 스프라이트 간 협력·연동을 구현한다.
