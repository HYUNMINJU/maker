• 블록 드래그하여 스크립트 영역에 연결하기
• 이벤트→제어→동작/형태 순으로 블록 조합하기

## 📙 03) Rogic 게임 프로젝트 실습

• Apple 스프라이트 복사하여 탕후루 캐릭터 모양 변형하기
• 냄비→물→설탕→과일꼬치 순서로 제조 게임 구조 만들기
• "탕후루 수" 변수 생성 후 완성 시 1씩 증가시키기
• 냄비올리기→물넣기→물완료→설탕완료→설탕코팅하기 신호 순차 전달하기
• 색깔 효과·크기 변경 블록 반복 적용하여 시각 피드백 추가하기
• "나 자신 복제하기" 블록으로 스프라이트 복제 생성하기

• 3핀 케이블 연결 시 ◁ 표시에 검정 선 맞춰 꽂기

## 📔 06) 게임메이커 실습1

• 하프프레임부터 접촉센서까지 16단계로 게임 로봇 조립하기
• 접촉센서1(D13)·접촉센서2(D12)·배터리케이스(B1) 배선하기
• 접촉센서로 손 방향을 선택하여 로봇과 참참참 대전하기
• 로봇·손·Round결과·꽃가루 4종 스프라이트 구성 파악하기
• 시작→로봇승리/패배→끝 신호 흐름으로 라운드 진행하기
• '라운드'·'점수' 변수로 5라운드 점수 관리하기
• 점수 3점 이상 시 꽃가루 연출, 이하 시 게임 종료하기

## 📖 08) 게임메이커 실습3

• ㅁ프레임·5x13프레임·배터리케이스·CPU보드·자이로센서·접촉센서 순으로 핸들 로봇 조립하기
• 접촉센서(D13)·자이로센서(A4·A5)·배터리케이스(B1) 3핀 케이블로 배선 후 블루투스 무선 연결하기
• 접촉센서 눌러 게임 시작하고 자이로센서 기울기x 값으로 자동차 좌우 이동하기
• 기울기x < -10이면 x좌표 -3, > 10이면 +3씩 변경하여 x좌표 -120~120 범위 내 이동 제한하기
• 차선·가로등 스프라이트를 0.5초마다 복제하여 y좌표 -10씩 내려 주행 스크롤 효과 구현하기
• 주변자동차와 거리 20 미만 시 충돌 신호 보내 효과음 재생 후 모든 스크립트 멈추기
• 추월횟수 40 초과 시 안개 등장, 구름 1~2초 랜덤 복제로 시야 방해하여 난이도 강화하기

## 🔖 09) 게임메이커 실습4

• 5X13프레임·120도프레임·접촉센서·회전위치센서·자이로센서·CPU보드 순으로 조준경 로봇 조립하기
• 접촉센서1(D13)·접촉센서2(D2)·회전위치센서(A0)·자이로센서(A4·A5)·배터리케이스(B1) 배선 후 블루투스 연결하기
• 회전위치센서 다이얼로 화면 좌우 이동하고 자이로센서 기울기y로 화면 위아래 이동하기
• 접촉센서1(D13) 눌러 자이로센서 '위로' 초기화 후 조준경 모양 1→9번 전환하여 게임 시작하기
• 회전위치센서 위치값 > 10이면 x좌표 -5, < -10이면 x좌표 +5씩 이동 후 위치값 0으로 초기화하기
• 접촉센서2(D2) 눌러 발사 신호·효과음 보내고 0.5초 쿨타임 적용하기
• 조준경 중앙색에 바퀴벌레 닿으면 명중 신호 보내 생존벌레 -1 감소 후 퇴치 모양으로 변경하기

---

## 📓 07) 게임메이커 실습2

• 자이로센서 부착 위치(위/앞/오른쪽/왼쪽/뒤)를 블록으로 지정하기
• 기울기(X·Y·Z 각도)·각속도 데이터를 무대 상단에서 실시간 확인하기
• 코뿔소·로보·시작신호 3종 스프라이트로 로데오 게임 구성하기
• 기울기x 값 조건으로 로보 모양 번호 ±1씩 변경하여 캐릭터 기울이기
• 모양 번호 1 또는 9 도달 시 실패 신호 보내고 생존 시간 표시하기
• 생존 시간에 따라 1~4단계 변수로 코뿔소 동작 속도 빠르게 조절하기
